# 단어 수어를 늘리는 법

단어는 **국립국어원 한국수어사전**(https://sldict.korean.go.kr/)에서 확인한 것만 넣는다.

| 파일 | 하는 일 |
|---|---|
| `js/wordBank.js` | 사전에서 확인한 35개 단어. 원문(사전 수형 설명 그대로), 항목 주소, 단계, 판정 힌트 |
| `docs/ILLUSTRATION-PROMPTS.md` | 단계마다 그림 한 장을 만드는 지시문 (`python3 dev/art/prompts.py` 로 다시 만든다) |
| `assets/incoming/` | 만든 그림을 넣는 곳. 이름은 `sl<항목번호>-<장>.png` |
| `dev/art/ingest.mjs` | 검사하고(`--apply` 없이), 붙인다(`--apply`) |
| `js/wordArt.js` | 단어별 그림 파일과 그 그림이 사전 기준인지. ingest 가 만든다 |
| `dev/words-check.mjs` | 출처 없는 단어, 빠진 그림, 겹치는 별칭을 막는다 |

화면에는 사전 기준 그림이 붙은 단어만 나오고, `wordBank` 의 기록을 쓴다.

## 갈래

| 갈래 | 단어 |
|---|---|
| 기본 | 안녕하세요, 감사합니다, 미안합니다, 괜찮아요, 네(확인 필요), 아니요, 도와주세요, 다시, 천천히, 이해했어요, 물, 화장실 |
| 감정 | 배고파요, 화나요, 슬퍼요, 기뻐요, 좋아요, 싫어요, 무서워요, 피곤해요, 아파요, 놀랐어요, 행복해요, 걱정돼요 |
| 지시어 | 나, 너, 우리, 여기(이것·이곳), 그(확인 필요) |
| 묻는 말 | 무엇, 어디, 언제, 누구, 왜, 어떻게 |
