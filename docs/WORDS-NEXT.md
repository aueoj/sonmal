# 다음에 넣을 단어

새 단어는 **국립국어원 한국수어사전**(https://sldict.korean.go.kr/)의 표제어를 확인한 뒤에만 넣는다.
`dev/words-check.mjs` 가 지킨다. 표제어 번호(`entryNo`)와 그 항목 주소(`sourceUrl`)가 없으면 점검이 깨진다.

```js
{ word: '슬프다', entryNo: '12345',
  sourceUrl: 'https://sldict.korean.go.kr/front/sign/signContentsView.do?origin_no=12345',
  수형: '…', 수향: '…', 수위: '…', 수동: '…', 비수지: '…',
  steps: ['…', '…'], hands: 1, source: '국립국어원 한국수어사전', recognizable: false }
```

수형·수향·수위·수동과 `steps` 는 사전의 수형 설명을 옮긴다. 그림은 `steps` 한 줄에 한 장이고,
지금 그림체(남색 선, 흰 상의, 어두운 배경과 빛)를 따른다.

## 목록

| 갈래 | 단어 |
|---|---|
| 감정 | 배고프다, 화나다, 슬프다, 기쁘다, 좋다, 싫다, 무섭다, 피곤하다, 아프다, 놀라다, 행복, 걱정 |
| 지시어 | 나, 너, 우리, 이것, 그것, 저것, 여기, 거기, 저기 |
| 묻는 말 | 무엇, 어디, 언제, 누구, 왜, 어떻게 |
| 대조 | 지금 있는 12개도 사전과 맞춰 본다 |
