# 낱말을 이어 연습하기

아래는 한국어 입력 예시다. 한국수어 문장 번역이나 문법 검수 결과가 아니다.
앱 화면 코드는 변경하지 않았으며, incoming 그림이 적용되기 전에는 새 낱말의 일러스트가 표시되지 않는다.

|연습 표현|낱말 순서|연습 목적|
|학교 어디|학교 → 어디|장소 묻기|
|누구|누구|사람 묻기|
|왜|왜|이유 묻기|
|나 기뻐요|나 → 기뻐요|감정 말하기|
|이해했어요 감사합니다|이해했어요 → 감사합니다|이해와 감사 표현|
|다시 천천히|다시 → 천천히|반복·속도 요청 낱말|
|먹다|먹다|식사 동작|

각 낱말의 원문·단계는 js/wordBank.js, 생성 지시문은 docs/ILLUSTRATION-PROMPTS.md를 따른다.
