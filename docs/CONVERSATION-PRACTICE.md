# 문장으로 낱말 이어 연습하기

앱 상단 **문장 연습**에서 6개 상황의 한국어 표현 48개를 고른다.
각 구성 낱말은 국립국어원 한국수어사전의 원문·항목 주소와 연결된 그림을 사용한다.
이 문장들은 한국수어 문법 번역이나 사전 문장 용례가 아니다.

전체 목록: `js/phrases.js`. 연결 검사: `node dev/phrase-test.mjs`.

예: 나는 수어를 배워요 → 나 / 수어 / 배우다.
병원이 어디예요 → 병원 / 어디.
가족을 사랑해요 → 가족 / 사랑.

각 낱말은 단계 설명, 그림, 원본 사전 영상 링크를 함께 표시한다.
