# 기본 회화 수어 출처

확인일: 2026-11-02 (한국 시간). 국립국어원 한국수어사전의 수형 설명 및 그림을 직접 확인했다.

생성 일러스트는 원자료를 참고한 학습용 초안이다. 전문가 검수, 문장 번역 검수 및 단어 인식 모델 학습을 완료했다는 뜻이 아니다. 원자료 그림은 링크로 제공하고 재배포하지 않는다.

사전 손가락 번호: 1지=검지, 2지=중지, 3지=약지, 4지=소지, 5지=엄지.

‘나는 너를 사랑해’는 나 → 너 → 사랑의 개별 낱말 연습으로 연결한다. ‘도와주세요’ 등 활용형도 대응 낱말 연습이며 부탁·시제·높임의 문법을 번역한 것이 아니다.

‘저기·저것’은 이번 검색에서 정확한 표제어를 확보하지 못해 등록하지 않았다. 미등록 표현은 지문자로 표시한다.
