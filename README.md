# 손말

말한 문장을 한글 지문자로 보여주고, 따라한 손모양을 다시 말로 읽어 주는 연습 도구.
브라우저만 있으면 된다. 서버도, 빌드도, 설치도 없다.

```
말하기  →  자모로 풀기  →  손모양 보여주기  →  따라한 것 읽기  →  다시 말하기
```

영상과 손 좌표는 브라우저 안에서만 처리되고 어디로도 전송되지 않는다.

## 열어보기

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000` 을 연다. 카메라와 마이크는 `https` 주소이거나
`localhost`에서만 열리므로 `file://` 로는 열리지 않는다. 자세한 안내는 [RUN.md](RUN.md).

`?mock=1` 을 붙이거나 화면의 **카메라 없이 둘러보기** 를 누르면 카메라 없이
합성 손으로 전체 흐름을 볼 수 있다.

음성 인식은 Web Speech API를 쓰므로 크롬·엣지 계열에서 동작한다. 그 밖의 브라우저에서는
아래 칸에 문장을 직접 입력하면 나머지는 똑같이 돌아간다.

카메라가 안 켜지면 **카메라 켜기** 를 눌렀을 때 어느 단계에서 막혔는지 단계별로 뜬다
(`js/diagnose.js`). 한 줄짜리 '열지 못했습니다' 대신, 다음에 무엇을 할지 고를 수 있게 한다.

## 어디까지 되나

**된다.** 한글 지문자 28자(자음 14 + 모음 14)를 말에서 풀어내 보여주고, 카메라로 따라한
손모양을 판정하고, 맞춘 자모를 다시 한글로 합쳐 음성으로 읽는다. 복합모음 7개는 두 자모로
풀고, 쌍자음 5개는 손을 옆으로 옮기는 움직임으로 가려낸다.

**회화 낱말.** 공식 한국수어사전의 33개 표제어를 참고한 일러스트와 원자료 링크를 제공한다.
상단 **회화 단어**에서 기본 회화·감정/상태·지시/질문을 선택하거나 검색한다.
`나는 너를 사랑해`, `배가 고파요`, `화나요`, `슬퍼요`, `이것` 등의 입력을 등록 낱말에 연결한다.
미등록 표현은 지문자로 표시한다. 긴 표현을 우선 찾으며 모르는 낱말의 일부를 임의로 잘라 바꾸지 않는다.

**한계.** 일러스트는 전문가 검수 전이다. 문장의 어순은 한국어 순서를 유지하는 낱말 연습이며,
한국수어 문장 번역이나 단어 동작 카메라 판정은 제공하지 않는다.
‘저기·저것’은 정확한 출처를 아직 확보하지 못해 미등록이다.
개별 설명·출처·검수 상태는 [docs/WORD-SOURCES.md](docs/WORD-SOURCES.md)에 기록했다.

**확인이 필요하다.** 손모양은 지문자 도표를 읽어 만든 것이다. 이웃 자모와 구별이 모호한
글자에는 화면에 '확인 필요'가 붙는다. 무엇이 모호한지는 [docs/HANDSHAPES.md](docs/HANDSHAPES.md)에 적어 두었다.

## 어떻게 만들어졌나

36장을 따로 그리지 않는다. 손 하나를 관절 각도로 그리고, 자모마다
**펴는 손가락 · 가리키는 방향 · 수향**만 데이터로 둔다. 선 굵기와 비례와 시점이 저절로 일치하고,
무엇보다 **같은 표현을 인식기가 그대로 쓴다.** 보는 모델과 판정하는 모델이 하나다.

판정은 좌표를 맞춰 보지 않는다. 랜드마크에서 폄 정도·가리키는 각도·손바닥 법선·벌림 각도·
고리 거리를 뽑아 비교하므로 손 크기, 카메라 거리, 화면 위치에 흔들리지 않는다.
틀렸을 때는 '다시 해보세요'가 아니라 **수형·수향·수동 중 무엇이 어긋났는지**를 말한다.

```
js/
  hangul.js        한글 ↔ 지문자 자모 (복합모음·겹받침 분해, 역합성)
  jamoData.js      28자 + 쌍자음 5자의 자세 데이터
  handRenderer.js  자세 → SVG 손 일러스트
  mockHand.js      자세 → 합성 랜드마크 (카메라 없는 개발·시험용)
  poseFeatures.js  랜드마크 21개 → 특징
  matcher.js       특징 ↔ 자세, 그리고 수어의 말로 된 피드백
  tracker.js       MediaPipe Hand Landmarker
  speech.js        음성 인식 · 음성 합성
  words.js         회화 낱말 33개, 활용형 연결, 지문자 대체 규칙
  app.js           네 단계를 잇는다
```

## 고치기

자모 하나를 고치려면 `js/jamoData.js`의 `mk(...)` 한 줄만 바꾸면 된다.
일러스트와 인식 기준이 함께 바뀐다. 고친 뒤에는

```bash
node dev/selftest.mjs
```

28자가 여전히 서로 구별되는지 확인한다. 합성 랜드마크 자기인식 시험이라
실제 카메라 정확도가 아니라 **자모끼리 갈라지는지**만 본다.

전체 표를 눈으로 보려면 `dev/sheet.html` 을 연다.

## 선 자리

[docs/RESEARCH.md](docs/RESEARCH.md)에 어떤 자료 위에 서 있는지, 그리고 아직 확인하지 못한
것이 무엇인지 적어 두었다. 요약하면 이렇다.

- 지문자는 윤백원이 1946년 한글 자모 모양을 본떠 창안한 한 손 체계다
- 수어의 의미는 수형·수향·수위·수동 네 가지로 갈린다 (문화체육관광부)
- 지문자 인식 연구는 MediaPipe 랜드마크로 정적 31자를 학습하고, 쌍자음은 손 무게중심 이동으로 가려낸다
- 단어 단위 한국수어 인식은 어휘를 닫아야 쓸 만하다. 20단어 98.3%, 77단어 89.0%, 공개 기준선 79.8%
- 단어 사전을 채울 곳은 국립국어원 한국수어사전, 공공데이터포털, AI Hub 수어 영상 데이터셋
